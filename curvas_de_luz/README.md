En esta carpeta se encuentran las curvas de luz reducidas con imágenes tomadas desde el Observatorio Astronómico Nacional San Pedro Martír para los asteroides, 
66146, 10032, 65628 y 163693. 

El archivo tiene como encabezado el número de puntos de la curva de luz, el nombre del asteroide y finalmente tres columnas (fecha JD - 2400000, Magnitud diferencial y error de la magnitud diferencial)
